== Description ==

Create ACF-powered wiki links. This is a beta release of the installed implementation. The codebase standards migration is planned for a later release.

== Installation ==

Install through the AlphaSys update controller or upload the release ZIP in WordPress. Activate the plugin after installation. Advanced Custom Fields is required for its features.
